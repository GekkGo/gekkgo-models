# Gulf car list

The list of cars sold in the Gulf that GekkGo downloads about once a week (`manifest.json` names the current version, its size and SHA-256, `cars_market.json` is the list). Each row is a make, model, year and engine with the fuel figure used for trip costs; every figure is labelled as an estimate in the app until the person's own fill-ups make it exact.

Built from public vehicle specification pages (engine, drive, stated fuel economy, trim names, model years) and engine-based estimates where a page states no figure. `hide` lists US EPA rows the list replaces with Gulf-specification rows.
